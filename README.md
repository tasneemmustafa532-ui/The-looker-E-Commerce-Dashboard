# 🛒 E-Commerce Performance & Sales Analytics Dashboard

## 📌 Overview
This repository contains an end-to-end data analysis project focusing on Brazilian E-Commerce dataset. The project evaluates overall sales performance, conversion funnels, retention trends, and sales forecasting to deliver actionable business insights through interactive dashboards.

---

## 🛠️ Tech Stack & Tools
* **Data Cleaning & Modeling:** Python (Pandas), SQL, Power Pivot, Power Query
* **Visualization & Dashboards:** Microsoft Excel, Figma (Layout Design)
* **Architecture:** Star Schema Data Model

---

## 🎯 Key Insights & Metrics (KPIs)
* **Sales & Revenue:** Evaluated total inventory ($490.7K) and overall revenue ($10.82M).
* **Conversion & Funnel:** Analyzed drop-off points across cart sessions and completed order statuses.
* **Customer Retention:** Tracked bounce rates and cohort retention over time.
* **Sales Prediction:** Projected revenue growth trends using historical order patterns.

* `/data`: Raw and processed star schema CSV datase
* `/dashboards`: Excel workbook containing interactive dashboards and pivot reports.
* `/scripts`: Python data cleaning notebooks and SQL data transformation scripts.
